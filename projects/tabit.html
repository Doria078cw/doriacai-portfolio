TabIt

Chrome Web Store ↗Product guide ↗GitHub ↗

Overview

TabIt is a Chrome extension that organizes open browser tabs into related groups. It uses tab titles and URLs to identify connections, with controls for grouping size and granularity and an option to organize new tabs automatically. All processing runs locally in the browser.

The problem

Everyday browsing can quickly turn into a crowded mix of tabs for work, study, entertainment, and personal tasks. TabIt groups related tabs to help people find what they need and move between activities without organizing every tab by hand.

How it works

Smart Regroup organizes ungrouped tabs while preserving existing groups. Optional automatic grouping places new tabs as you browse and reassesses them when their domain changes. Users can adjust group size and granularity, rename groups, and choose colors.

Local processing

TabIt compares tab titles and URLs using TF-IDF and Leiden community detection. Processing stays in the browser; the listing states that no browsing data is sent to external servers.
